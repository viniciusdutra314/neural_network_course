This a repository with assignments for an introductory neural network course.
The reports are writen in Typst 0.15.1 and the code is written in Python 3.12.
Each assignment is a separate folder with a Typst report (report.typ) and a Python script (main.py).
The python is managed using the uv ecossytem with basedpyright for type checking.
The reports are written in Portuguese (Brazilian Portuguese) and should be free of grammatical and textual errors in general.
Even though for Typst it doesn't matter if you break lines, always break lines to be easier to read in the editor.
